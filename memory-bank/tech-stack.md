# 技术栈推荐 (Tech Stack)

> **原则:** 最简单 + 最健壮 = Python 单体应用 + SQLite + 成熟稳定的库

---

## 核心技术选型

| 层级 | 技术选择 | 理由 |
|------|----------|------|
| **编程语言** | Python 3.11+ | 金融数据处理生态最成熟，学习成本低 |
| **数据库** | SQLite | 零配置、单文件、足够支撑百万级基金数据 |
| **实时行情** | AKShare | 免费开源，直接获取 A 股实时数据 |
| **定时任务** | APScheduler | 轻量级，内置进程，无需外部依赖 |
| **API 框架** | FastAPI | 高性能、自动生成 API 文档 |
| **计算库** | Pandas + NumPy | 金融计算事实标准 |

## 为什么选择这个方案？

### ✅ 简单
- **单进程运行**：`python main.py` 即启动全部服务
- **零外部依赖**：无需 Redis、MySQL、Docker
- **部署简单**：任意云服务器 / 本地电脑均可运行

### ✅ 健壮
- **SQLite**：支持 ACID 事务，数据不丢失
- **AKShare**：社区活跃，接口稳定（5000+ GitHub Stars）
- **Pandas**：久经考验的金融计算库
- **FastAPI**：自动数据校验，内置错误处理

## 后续升级路径

如果系统规模扩大，可平滑升级：

| 当前 | 升级到 | 触发条件 |
|------|--------|----------|
| SQLite | PostgreSQL | 数据量 > 10GB 或需并发写入 |
| APScheduler | Celery | 需分布式任务队列 |
| 单体应用 | Docker 容器 | 需多实例部署 |

---

> 💡 **建议**：先用最简方案跑通 MVP，再根据实际瓶颈升级。
