# FUNDBUG 使用指南

## 🚀 项目简介

FUNDBUG 是一个本地优先的基金净值估算系统，专为 Mac 用户设计。它通过实时抓取持仓股票行情，提供比官方更实时的净值估算，帮助投资者在盘中做出决策。

## ✨ 核心功能

*   **实时估值**：盘中每分钟自动更新，基于最新持仓和实时股价计算。
*   **误差修正**：自动回溯历史误差，使用 EWA 算法动态修正今日估值。
*   **隐私安全**：所有数据存储在本地 SQLite，不上传任何个人信息。
*   **自动同步**：添加基金时自动抓取最新持仓，无需手动维护。

## 🛠️ 快速开始

### 1. 启动服务

在终端中运行：

```bash
# 进入项目目录
cd ~/Documents/FUNDBUG

# 激活虚拟环境 (第一次运行时)
# source .venv/bin/activate

# 启动主程序
.venv/bin/python main.py
```

### 2. 访问界面

打开浏览器访问：[http://127.0.0.1:8000](http://127.0.0.1:8000)

### 3. 使用流程

1.  **添加基金**：在输入框输入 6 位基金代码（如 `000001`），点击“添加”。
2.  **查看估值**：
    *   **Est. NAV**: 实时预估净值
    *   **Est. Change**: 实时预估涨跌幅（红涨绿跌）
    *   **Last Update**: 上次更新时间（每分钟自动刷新）
3.  **删除基金**：点击卡片右上角的 `×` 按钮移除关注。

## 🧩 架构概览

*   **Frontend**: 原生 HTML/JS/CSS，无框架，轻量级。
*   **Backend**: Python FastAPI，高性能异步框架。
*   **Database**: SQLite，单文件存储，易于备份。
*   **Engine**:
    *   `Data Collector`: 抓取 AKShare 数据。
    *   `NAV Estimator`: 计算加权涨跌幅。
    *   `Scheduler`: 管理定时任务 (9:30-15:00)。

## ⚠️ 注意事项

*   **交易时间**: 实时估算仅在 A 股交易时间段（周一至周五 9:30-11:30, 13:00-15:00）有效。
*   **数据延迟**: 受限于 AKShare 接口，行情可能有 1-3 秒延迟。
*   **估算偏差**: 估算仅供参考，未披露持仓（主要为债券或现金）默认按 0% 涨跌幅处理。
